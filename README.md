# 우리학교 NEWS
중학교 2학년 국어 수업용 복합양식 기사 학습 사이트.

## 고정 주소로 접속하기
Pages 활성화 후 접속 주소: **https://dreamoflondonbridge-netizen.github.io/news/**

저장소 소유자가 GitHub에서 최초 한 번 설정합니다.

1. [Pages 설정](https://github.com/dreamoflondonbridge-netizen/news/settings/pages)을 엽니다.
2. Build and deployment의 Source를 **Deploy from a branch**로 선택합니다.
3. Branch를 **main**, 폴더를 **/(root)**로 고르고 **Save**를 누릅니다.
4. GitHub 배포 완료 후 위 주소로 접속합니다. 배포 결과는 저장소 Actions에서 확인할 수 있습니다.

이후 main 브랜치에 수정 사항을 올리면 GitHub Pages가 자동 갱신됩니다. 사이트 파일을 매번 내려받지 않아도 됩니다. 최신 화면이 보이지 않으면 Ctrl+Shift+R(Mac: ⌘+Shift+R)로 새로고침하세요. `.nojekyll`을 포함하여 별도 Jekyll 빌드 없이 정적 파일을 제공합니다.

편집한 기사 내용은 기기·브라우저별로 저장됩니다. 사이트 코드 업데이트와 기사 공동 저장은 별개이며, 다른 기기에는 JSON 내보내기/가져오기로 옮겨야 합니다. 모든 학생에게 편집 내용이 자동 전파되지는 않습니다.

## 클릭해서 바로 내려받기
**[실행용 ZIP 다운로드](https://github.com/dreamoflondonbridge-netizen/news/raw/refs/heads/main/news-explorer.zip)**

1. 위 ZIP을 다운로드하고 **압축을 풉니다**.
2. `news-explorer` 폴더 안의 **index.html**을 Chrome 또는 Edge로 엽니다.
3. 오른쪽 위 **선생님 편집실**에서 수정합니다. 수정 후 **수정한 사이트 파일 저장**을 누르면 보관할 수 있습니다.

GitHub의 초록색 Code → Download ZIP으로 전체 소스를 받았다면, 압축을 푼 뒤 루트의 **school-news.html**을 열어 주세요. 루트의 index.html은 개발용입니다.

## 가장 쉽게 열기 — 설치 없이
1. `school-news.html` 파일을 내려받습니다.
2. 파일을 더블클릭해 Chrome 또는 Edge에서 엽니다.
3. 오른쪽 위 **콘텐츠 편집**에서 기사와 자료를 수정합니다.
4. **수정한 사이트 파일 저장 ↓**을 누르면 편집 내용과 자료가 담긴 HTML 파일을 내려받습니다. 이 파일을 다른 컴퓨터로 옮겨 그대로 열 수 있습니다.

Python, Node.js, 서버, 회원가입이 필요하지 않습니다. 기본 이미지와 스타일, 실행 코드는 HTML 안에 포함되어 인터넷 없이 사용할 수 있습니다. 외부 URL로 추가한 사진·영상은 인터넷 연결이 필요합니다. 기기 파일로 추가한 자료는 HTML에 함께 저장됩니다.

편집 내용은 현재 브라우저에 자동 저장을 시도합니다. 파일로 연 페이지의 저장 동작은 브라우저 설정에 따라 달라질 수 있으므로, 수업 준비를 마치면 반드시 **수정한 사이트 파일 저장**으로 보관하세요. HTML 파일을 메신저로 공유할 때는 파일로 내려받은 뒤 브라우저에서 열어 주세요. 모바일의 파일 미리보기 앱에서는 실행되지 않을 수 있습니다.

## 수업 진행
- 기사 읽기는 글·사진·그림·영상이 실제 놓인 순서대로 진행합니다. 사진·그림을 누르거나 자료 아래 **자료 설명 보기**를 누르면 오른쪽에 해당 자료의 미리보기와 개별 질문·설명이 표시됩니다. 하단 다음도 세부 설명을 모두 공개한 뒤 다음 요소로 이동합니다. 확대는 **크게 보기** 버튼으로 사용할 수 있습니다.
- **형광펜**: 본문·전문의 문장을 드래그한 뒤 기사 위의 노랑·연두·분홍 버튼을 누릅니다. 여러 문단도 함께 표시할 수 있습니다. 선택 지우기·전체 지우기·마지막 작업 되돌리기를 지원하며, 표시 내용은 브라우저·JSON·오프라인 HTML에 저장됩니다. 문단 내용을 수정하면 그 문단의 표시는 지워집니다. 되돌리기는 현재 열린 페이지의 마지막 작업에 적용됩니다.
- PC에서는 양옆 여백을 줄이고 본문·설명·퀴즈를 수업용 큰 글씨와 선명한 대비로 표시합니다. 기사 위 **수업 화면**을 누르면 배너를 숨겨 화면을 넓게 쓰고 기사 크기를 100%로 복원합니다. **일반 화면**으로 돌아올 수 있으며, 수업 화면에서도 편집실과 학습 단계 이동을 사용할 수 있습니다.
- 기사 위의 **기사 화면 − 축소**로 본문과 자료를 함께 50~100% 크기로 볼 수 있습니다. 각 자료 아래의 **− 축소 / ＋ 확대**는 자료만 25~100% 크기로 조절합니다. 접거나 자르지 않으며 원래대로 복원할 수 있습니다. 설정한 크기는 브라우저·JSON·저장한 HTML에도 유지됩니다.
- 한옥 마당의 윷놀이를 그린 픽셀 아트 배너와 한지·나무·청록 계열 색감을 사용합니다. 퀴즈와 편집 패널도 같은 색감으로 구성했습니다.
- **기사 탐험 한 가지 흐름**으로 진행합니다. 기사에 놓인 순서대로 설명을 확인하고, 같은 요소에 완성된 퀴즈가 연결되어 있으면 바로 이어서 풉니다. 정답·해설 확인 후 다음 기사 내용으로 이동합니다. 퀴즈가 없으면 설명만 진행합니다.
- 하단 다음 또는 오른쪽 방향키는 세부 설명을 공개한 뒤 연결 퀴즈로 이동합니다. 퀴즈에서는 정답 확인 후 다음으로 진행하거나 **이 문제 건너뛰기**를 사용할 수 있습니다.
- 마무리에서는 이해한 문제, 다시 살펴볼 문제, 아직 풀지 않은 문제를 구분합니다. 결과에서 문제를 누르면 해당 단계로 돌아갑니다. 점수·보상·순위는 없습니다.
- 퀴즈 풀이 기록은 현재 페이지에서 유지되며 새로고침하면 초기화됩니다.
- **선생님 편집실 → 각 블록의 ‘탐험 퀴즈 편집’**에서 사용 여부, 문제, 보기(새 문제는 4개, 가져온 문제는 2~6개 지원), 정답, 해설, 관련 문단을 설정합니다. 질문과 모든 보기가 완성된 퀴즈만 해당 요소의 설명 뒤에 연결됩니다. 기사 설명과 퀴즈 데이터는 별도로 관리됩니다.
- 기존 JSON도 가져올 수 있습니다. 이전 예시 기사와 동일한 내용에는 예시 퀴즈를 연결하지만, 수정된 기사에는 관련 없는 예시 정답을 덧붙이지 않습니다.
- 제목·메뉴에는 주아체, 본문에는 고운돋움을 사용합니다. 글꼴은 오프라인 HTML에도 포함되며 SIL OFL 라이선스는 `assets/fonts`에 있습니다.
- 자료 숨기기·확대·비교를 사용할 수 있습니다. 상단 복합양식 메뉴에서 자료 모음을 열고 기사 위치로 이동할 수 있습니다.
- 블록을 추가·삭제·이동하면 학습 순서와 퀴즈 순서가 갱신됩니다. JSON과 오프라인 HTML에 퀴즈도 함께 저장됩니다.
- 배너는 AI 픽셀 아트, 기사 사진은 AI 생성 예시입니다. 실제 학교 취재 사진이 아닙니다. 영상은 MP4/WebM 파일이나 직접 재생 URL로 등록하세요.
- 사진은 개당 20MB, 영상은 개당 500MB 이하로 등록합니다. 영상은 실제 재생 가능 여부를 확인한 뒤 IndexedDB에 별도로 저장하므로 기사 설정의 localStorage 용량을 소모하지 않습니다. 브라우저 저장 공간이 부족하면 안내를 표시합니다. 큰 영상은 직접 재생 URL 사용을 권장합니다.

## 개발할 때 — Node.js만 필요
외부 패키지 설치 없이 저장소 루트에서 실행합니다.

```sh
npm start
```
브라우저에서 `http://localhost:3000`으로 접속합니다. 브라우저도 함께 열려면 `npm run open`을 사용하세요. 학생 기기에 공유할 공용 주소는 정적 호스팅에 게시해야 합니다. 서버는 기본적으로 모든 인터페이스의 3000번 포트에서 실행됩니다.

소스 수정 후 배포용 단일 HTML과 실행용 ZIP을 함께 갱신:

```sh
npm run build
```
검증: `npm test`.

## 영상 파일 업로드
- MP4(H.264/AAC) 또는 WebM을 권장합니다. 확장자가 MP4여도 내부 코덱에 따라 재생할 수 없는 파일이 있습니다. MOV 등은 현재 브라우저에서 실제 재생되는 경우에만 적용합니다.
- 편집실에서 업로드·저장·실패 상태를 확인합니다. 재생 불가 또는 저장 실패 시 기존 자료를 유지합니다.
- 영상은 현재 기기·브라우저의 IndexedDB에 보관합니다. 브라우저 사이트 데이터를 삭제하면 영상도 삭제될 수 있습니다.
- JSON/HTML 내보내기는 저장된 영상을 실제 데이터로 포함하므로 다른 기기로 옮길 수 있습니다. 큰 영상이 포함되면 파일 생성 시간이 길고 크기도 커집니다.

## 데이터 구조
`data.js`의 `blocks`는 고유 ID를 가진 순서 있는 콘텐츠이고, `lessons`는 ID별 별도 학습 데이터입니다. 관련 문단은 `relatedIds`로 연결합니다. `buildLearningSteps`는 블록 ID로 연결된 `lessons`와 `quizzes`를 사용해 각 요소의 설명 바로 뒤에 활성화된 퀴즈를 배치합니다. 기사 순서대로 한 번에 진행하며 퀴즈만 따로 다시 읽는 모드는 없습니다. `scripts/build.mjs`는 이미지·CSS·JavaScript를 포함한 `school-news.html`을 생성합니다.
